DATABASE
========
This v1 frontend is designed to reuse the existing working Supabase project from the prototype.
Expected objects:
- matches
- clubs
- competitions
- score_events
- admin_users
- RPC: is_admin
- RPC: record_score
- RPC: undo_last_score
- RPC: set_match_status
- RPC: admin_create_match
- RPC: admin_assign_reporter_by_email

If the old prototype is still working, do not rebuild the database yet.
